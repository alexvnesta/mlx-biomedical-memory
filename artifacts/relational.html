Controlled local experiment · 4-bit LongCat · frozen backbone

Can scoped memory handle richer relationships?

24 qualified atomic values, six reusable rules, 48 new synthetic worlds and 12 ARAX annotation audits. Answer correctness and executable evidence support are scored separately.

Measured conclusion: With complete gold evidence, scoped rules produced 20/60 supported answers, versus 30/60 with text rules and 16/60 with rules disabled. For model-planned graph queries, scoped rules produced 7/60, versus 14/60 with text rules. This run does not demonstrate an advantage over supplying the rule as text.

972 primary outcomes plus 212 separately labeled post-hoc diagnostic outcomes. Explicit rule routing is supplied to every condition. Graph agents select their own queries. Synthetic causal rules are assumptions; ARAX cases summarize retained annotations. This is not a rare-disease discovery or clinical validation study.

Read the boundaries

Gold evidence is an oracle control. Correct final labels alone do not establish valid reasoning. Proof checks use declared rules and retrieved records; complete backend lookups can certify absence. Different primary providers do not establish independent experiments. A trained rule definition is not an autonomous scientific theory.
